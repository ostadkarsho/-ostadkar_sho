استادکار شو — بسته آماده نصب روی گوشی

این بسته نسخه وب‌اپ (PWA) است؛ APK مستقل نیست. برای اینکه آیکون نصب شود و برنامه مثل اپ باز شود، باید فایل‌ها را روی یک آدرس HTTPS منتشر کنید (مثلاً GitHub Pages).

مراحل کلی انتشار با GitHub Pages:
۱) فایل ZIP را از حالت فشرده خارج کنید.
۲) فایل‌های داخل پوشه را در ریشه مخزن GitHub خود آپلود کنید؛ فایل اصلی باید دقیقاً index.html باشد.
۳) در مخزن بروید به Settings → Pages، گزینه Deploy from a branch را انتخاب کنید و branch اصلی و /(root) را ذخیره کنید.
۴) پس از فعال‌شدن Pages، لینک سایت را با Chrome گوشی باز کنید.
۵) از منوی سه‌نقطه Chrome گزینه Install app یا Add to Home screen را بزنید.

توجه: تا وقتی روی HTTPS منتشر نشده، نصب PWA از روی فایل محلی انجام نمی‌شود. این نسخه فعلی برنامه را بسته‌بندی می‌کند؛ هنوز APK واقعی تولید نمی‌کند و بخش سفارش آنلاین هم به سرور نیاز دارد.
